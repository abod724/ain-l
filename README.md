 لغة عين للبرمجة

بيئة برمجة عربية تفاعلية تتيح للمبتدئين كتابة الأكواد وتشغيلها بأوامر عربية بسيطة، مما يزيل حاجز اللغة الإنجليزية ويسهل تعلم أساسيات البرمجة.

 مميزات اللغة:
- **متغيرات:** تعريف وتخزين القيم.
- **حلقات تكرارية:** استخدام `كرر` مع النطاقات.
- **شروط:** استخدام `إذا` لاتخاذ القرارات.
- **مكتبات رياضية:** دعم `جذر`، `قوة`، و `عشوائي`.

 جرب المنصة:
يمكنك تجربة كتابة الأكواد وتشغيلها مباشرة من خلال الرابط التالي:
**[اضغط هنا لتجربة لغة عين](https://abod724.github.io/taheel-employees/)**

 قيد التطوير:
- إضافة الشروط المتقدمة (`وإلا`).
- تحسين دعم القوائم (Lists).
- إضافة المزيد من الأمثلة التعليمية.
